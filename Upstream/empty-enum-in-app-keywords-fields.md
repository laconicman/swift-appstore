# `fields[appKeywords]` parameters declare `enum: []`

Upstream note for Apple's App Store Connect OpenAPI specification (v4.5, downloaded
2026-09-23, upstream sha256 `1e8ef250…6927b2`). **Status: verified** — reproduced with the
commands below. Feedback not yet filed.

---

## Feedback draft

**Title:** App Store Connect OpenAPI spec: `fields[appKeywords]` query parameters have an empty
`enum` array, breaking code generation

### Summary

Five `GET` operations declare a `fields[appKeywords]` query parameter whose array item schema is

```json
{ "type": "string", "enum": [] }
```

An empty `enum` is technically allowed by JSON Schema but it describes a type with **no valid
values**, which is not what the API does (the parameter accepts field names such as `name`).
Generators that map string enums to language enums emit an enum with zero cases. In Swift that
does not compile:

```
error: an enum with no cases cannot declare a raw type
error: cannot automatically synthesize 'Decodable' conformance for empty enum
```

### Locations

All five, as JSON pointers into `openapi.oas.json` (v4.5):

```
/paths/~1v1~1appCustomProductPageLocalizations~1{id}~1searchKeywords/get/parameters/2/schema/items
/paths/~1v1~1appCustomProductPageVersions~1{id}~1appCustomProductPageLocalizations/get/parameters/5/schema/items
/paths/~1v1~1appStoreVersionLocalizations~1{id}~1searchKeywords/get/parameters/2/schema/items
/paths/~1v1~1appStoreVersions~1{id}~1appStoreVersionLocalizations/get/parameters/5/schema/items
/paths/~1v1~1apps~1{id}~1searchKeywords/get/parameters/2/schema/items
```

Operations: `appCustomProductPageLocalizations_searchKeywords_getToManyRelated`,
`appCustomProductPageVersions_appCustomProductPageLocalizations_getToManyRelated`,
`appStoreVersionLocalizations_searchKeywords_getToManyRelated`,
`appStoreVersions_appStoreVersionLocalizations_getToManyRelated`,
`apps_searchKeywords_getToManyRelated`.

Every other `fields[…]` parameter in the document lists its field names; these five are the
only `enum: []` occurrences in the whole file.

### Expected

Either list the `AppKeyword` attribute names (the `AppKeyword` schema in `components/schemas`
has a single attribute, `name`), or omit `enum` and leave the item as a plain string.

### Impact

Any operation whose parameters include one of these five cannot be generated by
swift-openapi-generator (and, reasoned, by other generators that require enum cases). Two of
them — `appStoreVersions_appStoreVersionLocalizations_getToManyRelated` and
`appStoreVersionLocalizations_searchKeywords_getToManyRelated` — sit on the core App Store
publishing path (listing a version's localizations).

---

## Local mitigation

`asc-spec-tool` normalizes the document when vendoring: any `enum` key whose value is an empty
array is removed, leaving the enclosing `{"type": "string"}` intact. Nothing else is touched.
The count of removed keys is recorded in `Sources/AppStoreOpenAPI/spec-manifest.json` under
`vendored.normalizations.emptyEnumsDropped` (currently `5`), and the upstream and vendored
sha256 are both pinned so the edit is auditable.

The alternative — excluding the five operations via the generator config's `filter` — was
rejected because two of them are needed by the `release` tier, and because dropping a
meaningless `enum: []` is a strictly type-widening edit (the generated parameter becomes
`[String]?` instead of an uninhabited type).

## Verification (2026-09-23, Swift 6.1.2, Linux x86_64)

Count the occurrences in the pristine upstream file:

```sh
python3 -c 'import json,sys
def walk(o,p):
    if isinstance(o,dict):
        if o.get("enum")==[]: print(p)
        for k,v in o.items(): walk(v,p+"/"+k)
    elif isinstance(o,list):
        for i,v in enumerate(o): walk(v,p+"/"+str(i))
walk(json.load(open("openapi.oas.json")),"")' | wc -l      # → 5
```

Reproduce the generator failure by vendoring the upstream file unmodified and building the
`release` tier:

```sh
cp openapi.oas.json Sources/AppStoreOpenAPI/openapi.json
swift build --target AppStoreOpenAPI                        # fails: "an enum with no cases cannot declare a raw type"
```

Confirm the mitigation:

```sh
swift run asc-spec-tool --from openapi.oas.json             # emptyEnumsDropped: 5
swift build --target AppStoreOpenAPI                        # Build of target: 'AppStoreOpenAPI' complete!
```

## When it can be retired

When a spec download reports `emptyEnumsDropped: 0`, the normalization is a no-op and this note
can be moved to a "resolved" table. `swift run asc-spec-tool --check` reports operation-level
drift between the vendored and downloaded documents, which is the moment to look.
